# Chat With PDF

A web app that allows users to upload a PDF and ask questions about its content using AI.

## 🚀 Live Demo

👉 [Try Chat With PDF](https://chat-with-pdf-atam.onrender.com)

## ✨ Features

- Upload PDF
- Ask questions about the PDF
- AI-powered answers
- RAG-based document search
- Vector database for document embeddings

## 🛠️ Tech Stack

- HTML, CSS, JavaScript
- Node.js
- Express.js
- Ollama
- Qdrant
- PDF Parse
